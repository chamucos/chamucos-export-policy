Privacy Policy

Last updated: October 17, 2026

Operator and purpose

CHAMUCOS Export Research is a private-use seller tool operated by BAR CHAMUCOS, Ginza 6-2-6, West Building 2F, Chuo-ku, Tokyo, Japan. Its seller connection is restricted to the operator's authorized owner account. It supports product research and preparation for the owner's eBay selling activities.

Data collected and access requested

We use the owner's ChatGPT account identifier and email to restrict access. When the owner grants authorization on eBay, the application receives an OAuth access token and refresh token. The requested permissions cover listing and inventory management and read-only access to selling account settings. The application does not collect the owner's eBay password. The seller connection currently saves authorization credentials; listing creation and publication are not yet implemented.

Storage and use

Production API credentials and seller tokens are encrypted before being stored in the application's server-side database. They are used only for the owner's authorized integration with eBay and are not displayed in the browser or included in application error messages. A short-lived authorization state is used to validate the login callback and is consumed once.

Service providers and disclosure

The tool runs on OpenAI Sites hosting with Cloudflare infrastructure. Authorized API requests are sent to eBay. Credentials are not sold or shared for advertising. Hosting providers process requests and technical records as part of operating the service.

Retention and deletion

The owner can delete stored seller tokens from the seller connection page. Expired login states are removed during subsequent connection attempts. To revoke permissions at eBay, remove this application in the eBay account settings. Deleting the seller token does not delete the separately saved application API credentials. For questions or requests concerning this tool, contact the operator at BAR CHAMUCOS at the postal address above.
